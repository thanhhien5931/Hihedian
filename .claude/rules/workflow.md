# Quy trình làm việc

- Không thêm thư viện mới khi chưa cần thiết; nếu thêm, giải thích lý do.
- Giai đoạn Next.js: chạy `npm run build` và `npm run lint` sau mỗi thay đổi đáng kể.
- Giai đoạn HTML tĩnh: kiểm tra trang không có lỗi JavaScript (console) sau khi sửa `main.js`.
- Thay đổi giao diện lớn: bắt buộc làm theo `screenshot-verification.md`.
